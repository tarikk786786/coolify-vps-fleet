Runs permanently in the cloud on dedicated virtual servers (Oracle Cloud Always-Free ARM 4-Core 24GB, Hetzner, DigitalOcean). Never goes to sleep, immune to home internet/power outages, and accessible worldwide with direct apex domain support.

Local WSL2 + Cloudflare Tunnel Mode

Runs Coolify on your Windows WSL2 machine with automated Cloudflare Zero-Trust edge tunneling. Best for zero-cost development, local building, and staging environments without any monthly VPS bill.

How 1-Click Cloud VPS Deployment Works

  1. Step 1: Obtain any Cloud VPS (e.g. Oracle Cloud Always-Free 4-core 24GB RAM or Hetzner €3.79/mo).
  2. Step 2: Enter your VPS Public IP and click Deploy 24/7 to Cloud VPS.
  3. Step 3: The automated runner connects over SSH, installs Docker, pulls Coolify v4 engine, configures UFW firewall, and initializes the control plane.
  4. Step 4: In Cloudflare or your domain registrar, add an A Record pointing coolify.tarikislam.in to your VPS Public IP.
